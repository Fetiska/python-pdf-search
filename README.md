поиск по текстовым pdf, кейс 10

| действие | url | метод | запрос и ответ |
| --- | --- | --- | --- |
| поиск документов | `/documents` | GET | `q` — обязательная непустая строка, возвращает до 10 файлов по убыванию релевантности tf-idf: `file` — имя файла, `snippet` — фрагмент текста, без совпадений — `[]`, пустой запрос — 400 |

пример: `/documents?q=охрана%20труда` → `[{"file":"safety.pdf","snippet":"инструкция по охране труда"}]`

pdf читаются из папок в yml при запуске сервера через pypdf, поиск без учёта регистра, лемматизации и стемминга

swagger: `python3 -m http.server 8000`, затем открыть http://localhost:8000
